# React v19 + TypeScript v7 + Vite v8

This project is exploring the usage of Typescript v7 in React projects.

## Development information

Important: This project uses **pnpm**

### Project setup

```bash
pnpm install --frozen-lockfile
```

### Running the development server

```bash
pnpm dev
```

### Linting the code

```bash
pnpm lint
```

### Building project for production

```bash
pnpm build
```
